# Сапёр

Небольшая игра на Python и Pygame, вдохновлённая классическим «Сапёром».

Проект находится в разработке. На данный момент реализована основная механика одного уровня.

## Текущая версия

Сейчас в игре есть:

* игровое поле (размер поля можно задать);
* случайное размещение мин;
* подсчёт количества мин вокруг клетки;
* открытие клеток;
* автоматическое открытие безопасной области;
* безопасный первый ход;
* ЛКМ для обычного открытия клетки;
* ПКМ для специального действия;
* возможность проиграть при открытии мины;
* перезапуск игры после проигрыша;
* отображение графики клеток и игровых объектов;
* базовый игровой цикл на Pygame.

## Планируемые возможности

В дальнейшем планируется добавить:

* несколько уровней сложности;
* общий таймер прохождения игры;
* увеличение доступного времени между уровнями;
* зелья маны;
* бонусы времени;
* ограниченное время жизни бонусов на поле;
* полноценную систему уровней;
* экран главного меню;
* экран победы;
* экран поражения;
* дополнительные игровые эффекты и звуки;
* улучшение визуального оформления.

## Управление

| Действие                         | Клавиша       |
| -------------------------------- | ------------- |
| Открыть клетку                   | ЛКМ           |
| Отметить клетку                  | ПКМ           |
| Выйти из игры                    | Закрытие окна |

### Основные файлы

**`main.py`**
Главный файл игры. Отвечает за запуск Pygame, игровой цикл, обработку событий и отрисовку.

**`board.py`**
Содержит игровую логику поля: создание клеток, размещение мин, подсчёт мин и открытие области.

**`cell.py`**
Описывает отдельную клетку игрового поля и её состояние.

**`assets.py`**
Загрузка игровых изображений и других ресурсов.

**`settings.py`**
Настройки игры: размеры окна, размеры поля, количество мин, FPS и другие параметры.

## Статус проекта

Проект находится в активной разработке.

Основная механика первого уровня уже работает, дальнейшая разработка будет сосредоточена на системе уровней, времени, бонусах и улучшении игрового оформления.
